### Who Am I?

My name is Atul Kamath, and I'm currently a B.E. Computer Science student at Visvesvaraya Technological University (VTU). Ever since I found about raspberry Pi's watching ETA prime and Nova spirit tech's youtube channel back in sixth grade i've always been curious about what goes onto building such a small computer and the best part of it being able to play retro games. Then skip to college ,I first started using ubuntu I always wondered what goes into building something like it , that led me to discover more about the linux kernel and since then its always been my intrest to keep trying to find what about the crazy things a particular peice of systems software is capable of doing.

I've spent my entire college journey so far living in a terminal, customizing my environment, and enjoying the freedom and control that the Linux ecosystem provides and reaching the end game of using linux which would probably be using window managers(I use Sway WM).
